# vssinghh Homebrew Tap

Homebrew formulas for developer tools by [@vssinghh](https://github.com/vssinghh).

## Install `leaktap`

```bash
brew install vssinghh/tap/leaktap
```

Or tap first and install:

```bash
brew tap vssinghh/tap
brew install leaktap
```

Source, documentation, and SHA-256 build provenance attestations: https://github.com/vssinghh/leaktap
